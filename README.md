## 📖 О проекте

**SDVGacha** — это масштабный трехмерный аниме Action-RPG проект в стиле игр **Hoyoverse** (Genshin Impact, Zenless Zone Zero, Honkai Star Rail), разработанный на движке **Godot Engine 4**.

Игра полностью адаптирована как для **ПК (клавиатура и мышь)**, так и для **смартфонов и планшетов (виртуальный джойстик, сенсорные кнопки действий и свайп-обзор камеры)**.

---

## ✨ Ключевые особенности

### 🎭 Игровые персонажи и отряд (1–9)
* **Ху Тао (Hu Tao)** — пиро-чародейка ритуального бюро «Ваншэн». Стремительные удары клинком, огненные вихри и мистические пламенные бабочки.
* **Эллен Джо (Ellen Joe)** — крутая горничная-акула из *Victoria Housekeeping* (*Zenless Zone Zero*). Орудует ледяными ножницами-клинками, обладает собственным подвижным акульим хвостом и ледяными навыками.
* **Система вербовки и отряда:** Взаимодействуйте с персонажами в мире (кнопка **[F]**), чтобы запустить кинематографичный диалог в стиле визуальной новеллы. После диалога союзник присоединяется к вашему отряду, и вы можете мгновенно переключаться между бойцами горячими клавишами **1–9** или тапом по слотам на экране!

### 💥 Модульная разрушаемость объектов и построек (Multi-Tier Demolition)
* **3-этажная Японская Школа (桜ヶ丘学園):** Полностью разрушаемый архитектурный комплекс! Каждый этаж, крыша с часовой башней, спорткомплекс, футбольные ворота, школьные заборы, парты и доски обладают собственным здоровьем и разрушаются независимо с физическими обломками бетона, стекла, дерева и меловой пыли.
* **Поэтапное разрушение крупных построек (Пагоды, Небоскребы, Мосты, Карстовые пики):**
  * При **66% HP** обрушиваются верхние шпили, часовые башни и крыши.
  * При **33% HP** разрушаются средние ярусы, балконы и фасадные перекрытия.
  * При **0% HP** происходит полное обрушение основания с разлетом орбов опыта и лута!

### 🗺️ Уникальные биомы и открытый мир
1. **Старшая Школа Сакурагаока** — 3 этажа классов, шкафчики гэтабако, часовая башня, смотровая площадка на крыше и беговой стадион.
2. **Имперский Город Ли Юэ** — торговый проспект, резная 5-ярусная Пагода Дракона и арочный Лунный мост через реку.
3. **Долина Цветущей Сакуры и Озеро Лотосов** — живописные азиатские просторы, сакуровые и лазурные слаймы, сундуки с сокровищами.
4. **Проклятые Земли Нежити (Corrupted Lands)** — склепы душ, гигантские костяные обелиски, разлагающиеся деревья и некро-твари.
5. **Кибер-Город Нео-Токио (Cyber District)** — неоновые голограммы, хромированные конструкции, летающие боевые дроны и кибер-стражи.

### 🎨 Графика и визуал
* **Genshin Cel-Shading:** Фирменный аниме-шейдер с мягким шейдингом кожи, контурным светом (rim light), анизотропным сиянием волос и стилизованными глазами.
* **Реалистичная аниме-вода:** Процедурная каустика, мягкие береговые градиенты по Z-буферу, анимированная пена и физические круги на воде при плавании.
* **Динамическая смена времени суток:** Рассвет, ясный полдень, закат и звездная ночь с регулируемым освещением и небесной панорамой.

## 🎮 Управление

### 💻 Персональный компьютер (ПК)
| Действие | Клавиша / Ввод |
| :--- | :--- |
| **Движение** | `W`, `A`, `S`, `D` (любая раскладка клавиатуры) / Стрелки |
| **Обзор камеры** | Мышь (зажатие / авто-захват курсора по клику) |
| **Масштаб камеры (Zoom)** | Колёсико мыши |
| **Обычная атака / Серия комбо** | `ЛКМ` (левая кнопка мыши) |
| **Заряженная атака** | Зажать `ЛКМ` (0.4с) |
| **Рывок / Уклонение** | `ПКМ` (правая кнопка мыши) / `Shift` |
| **Прыжок / Планер** | `Пробел` |
| **Стихийный навык** | `E` |
| **Взаимодействие (Диалог / Сундук)** | `F` (любая раскладка EN/RU) или клик мыши |
| **Переключение персонажа в отряде** | `1` — `9` |
| **Быстрое исцеляющее зелье** | `Q` / `Z` |
| **Окно персонажа и инвентарь** | `C` |
| **Захват цели** | `T` |
| **На весь экран** | Кнопка `⛶ Экран` или клавиша `F11` |

### 📱 Смартфоны и планшеты
* **Бег:** Левый виртуальный джойстик.
* **Обзор:** Свайп пальцем по правой половине экрана.
* **Бой и навыки:** Круглые сенсорные кнопки в правом нижнем углу.
* **Отряд:** Тап по иконке персонажа в правом верхнем углу.
