## 📖 О проекте

**SDVGacha** — это масштабный трехмерный аниме Action-RPG проект в стиле игр **Hoyoverse** (Genshin Impact, Zenless Zone Zero, Honkai Star Rail), разработанный на движке **Godot Engine 4**.

Игра полностью адаптирована как для **ПК (клавиатура и мышь)**, так и для **смартфонов и планшетов (виртуальный джойстик, сенсорные кнопки действий и свайп-обзор камеры)**.

---

## ✨ Ключевые особенности

### 🎭 Игровые персонажи и отряд (1–9)
* **Ху Тао (Hu Tao)** — пиро-чародейка ритуального бюро «Ваншэн». Стремительные удары копьем/клинком, огненные вихри и мистические пламенные бабочки.
* **Эллен Джо (Ellen Joe)** — крутая горничная-акула из *Victoria Housekeeping* (*Zenless Zone Zero*). Орудует ледяными ножницами-клинками, обладает собственным механическим хвостом и ледяными навыками.
* **Система вербовки и отряда:** Взаимодействуйте с персонажами в мире (кнопка **[F]**), чтобы запустить кинематографичную катсцену и диалог в стиле визуальной новеллы. После диалога союзник присоединяется к вашему отряду, и вы можете мгновенно переключаться между бойцами горячими клавишами **1–9** или тапом по слотам на экране!

### 📱 Полная адаптация для смартфонов и планшетов
* **Виртуальный аналоговый джойстик** в левой нижней зоне с динамическим якорем под палец.
* **Сенсорные кнопки действий** справа:
  * ⚔️ **Атака** (серия комбо-ударов и заряженный выпад)
  * 🦘 **Прыжок** (прыжки и раскрытие ветряного планера в воздухе)
  * 💨 **Рывок** (уклонение с временной неуязвимостью)
  * 🔥 **Стихийный навык** (с круговым таймером перезарядки)
  * 💬 **[F] Взаимодействие** (диалоги с NPC, сбор сундуков)
  * 🧪 **[Q] Зелье** (быстрое восстановление здоровья)
  * 🎯 **Цель** (авто-захват ближайших противников)
* **Сенсорный обзор (Touch Look):** Плавное вращение камеры в 3D свайпом по правой части экрана.
* **Переключатель интерфейса:** Кнопка **`📱 Сенсор: ВКЛ / ВЫКЛ`** на верхней панели позволяет включать или скрывать виртуальные кнопки в любой момент.

### 🗺️ Уникальные биомы и монстры
1. **Долина Цветущей Сакуры и Озеро Лотосов** — живописные азиатские просторы, сакуровые и лазурные слаймы, сундуки с сокровищами.
2. **Чумные Земли Нежити (Corrupted Lands)** — скверна, гигантские костяные обелиски, разлагающиеся деревья, чумные упыри и некро-твари.
3. **Кибер-Город Нео-Токио (Cyber District)** — неоновые голограммы, хромированные конструкции, летающие боевые дроны и кибер-стражи.

### 🎨 Графика и визуал
* **Genshin Cel-Shading:** Фирменный аниме-шейдер с мягким шейдингом кожи, контурным светом (rim light), анизотропным сиянием волос и стилизованными глазами.
* **Реалистичная аниме-вода:** Процедурная каустика, мягкие береговые градиенты по Z-буферу, анимированная пена и физические круги на воде при плавании.
* **Динамическая смена времени суток:** Рассвет, ясный полдень, закат и звездная ночь с регулируемым освещением и небесной панорамой.

## 🎮 Управление

### 💻 Персональный компьютер (ПК)
| Действие | Клавиша / Ввод |
| :--- | :--- |
| **Движение** | `W`, `A`, `S`, `D` (относительно камеры) |
| **Обзор камеры** | Мышь (зажатие / захват курсора) |
| **Масштаб камеры (Zoom)** | Колёсико мыши |
| **Обычная атака / Серия комбо** | `ЛКМ` (левая кнопка мыши) |
| **Заряженная атака** | Зажать `ЛКМ` (0.4с) |
| **Рывок / Уклонение** | `ПКМ` (правая кнопка мыши) / `Shift` |
| **Прыжок / Планер** | `Пробел` |
| **Стихийный навык** | `E` |
| **Взаимодействие (Диалог / Сундук)** | `F` |
| **Переключение персонажа в отряде** | `1` — `9` |
| **Быстрое исцеляющее зелье** | `Q` / `Z` |
| **Окно персонажа и снаряжение** | `C` |
| **Захват цели** | `T` |
| **Анти-застревание** | `U` / `F8` |

### 📱 Смартфоны и планшеты
* **Бег:** Левый виртуальный джойстик.
* **Обзор:** Свайп пальцем по правой половине экрана.
* **Бой и навыки:** Круглые сенсорные кнопки в правом нижнем углу.
* **Отряд:** Тап по иконке персонажа в правом верхнем углу.
